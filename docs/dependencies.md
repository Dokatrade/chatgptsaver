# 📦 Зависимости

## npm-пакеты (`package.json`)

| Пакет | Версия | Назначение |
|-------|--------|-----------|
| `pdfmake` | ^0.3.3 | Генерация PDF-документов |
| `@fontsource/noto-emoji` | ^5.2.11 | Шрифт Noto Emoji для PDF |

### Установка

```bash
npm install
```

> Пакеты используются **только для сборки шрифтов** (`build-fonts.js`, `download-font.js`). В рантайме расширение использует файлы из `lib/`.

## Библиотеки в `lib/`

Расширение Chrome не поддерживает npm-модули напрямую, поэтому все runtime-зависимости хранятся как минифицированные файлы в `lib/`.

| Файл | Источник | Назначение |
|------|---------|-----------|
| `pdfmake.min.js` | pdfmake | Основная библиотека генерации PDF |
| `vfs_fonts.min.js` | pdfmake | Стандартные шрифты (Roboto) |
| `vfs_fonts_custom.js` | Собственная сборка | Кастомные шрифты (Noto Emoji) |
| `html2pdf.min.js` | html2pdf.js | Альтернативный PDF-генератор |
| `jspdf.min.js` | jsPDF | Зависимость html2pdf |
| `NotoEmoji-Regular.ttf` | Google Fonts | Шрифт эмодзи (исходник) |

## Шрифты

### Noto Emoji
- Используется для отрисовки эмодзи в PDF (pdfmake не поддерживает эмодзи из коробки)
- Исходный файл: `lib/NotoEmoji-Regular.ttf`
- Скомпилирован в `lib/vfs_fonts_custom.js` через `build-fonts.js`

### Пересборка шрифтов

```bash
# Скачать свежий шрифт
node download-font.js

# Собрать VFS-файл для pdfmake
node build-fonts.js
```

## Правила работы с зависимостями

1. **Не использовать CDN** — все библиотеки хранятся локально (требование Chrome-расширений)
2. **Минифицированные версии** — в `lib/` хранить только `.min.js`
3. **Обновления осторожно** — перед обновлением проверить совместимость с Manifest V3
4. **`node_modules/` не коммитить** — папка в `.gitignore`
5. **`lib/` коммитить** — эти файлы нужны для работы расширения
6. **Новые npm-пакеты** — добавлять только при реальной необходимости, избегать раздувания
